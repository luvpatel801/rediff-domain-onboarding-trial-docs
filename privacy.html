Rediff Domain Onboarding — private trial privacy notice

Operator for this trial: Luv Patel, luvpatel801@gmail.com.

Data used

When you enter a domain, the localhost portal reads public registration, DNS, and provider information. Those requests disclose the domain name to the relevant registration services, DNS resolvers, authoritative DNS servers, and Domain Connect service, where available. If you connect Vercel, Vercel provides a short-lived connection code and a token for the approved account access. The portal uses that token to read the DNS zone for the exact entered domain. If you separately approve the TXT test, the portal uses the token to add one test record, check it, remove it after two minutes, and check again.

Storage and access

The trial stores the entered domain, discovery results, and any provider-zone snapshot in the local server's process memory. A browser cookie identifies the local session. Sessions stop being accessible after 30 minutes; expired entries are removed when looked up, or when the local server exits. The Start again action removes the current entry sooner. The code does not write these session results to a database. The Vercel token stays in server memory for up to 10 minutes while you decide whether to run the optional test; during the test it remains in memory until the removal attempt finishes. It is not saved in a file, database, or browser page. The integration requests Vercel Domains: Read/Write permission. Discovery alone does not change DNS.

Other services

Vercel handles the account connection. Public discovery contacts IANA/registry/registrar registration services, DNS services, and a Domain Connect provider when one is published. Those services may process requests under their own policies. If these pages are published with GitHub Pages, GitHub may log visitors' IP addresses for security. The localhost portal has no advertising or analytics integration in this trial.

Choices and contact

You can avoid connecting a provider and still view public information. You can clear the local review with Start again, stop the local server, and revoke the integration in Vercel. For questions or a request about this trial's data, contact luvpatel801@gmail.com.
