Rediff Domain Onboarding — Vercel private trial guide

This guide describes the current localhost trial. It does not offer a public Rediff service.

What it does

  1. Enter a domain in the local portal.
  2. The portal reads public registration and DNS information to identify the registrar, active DNS host, current mail destination, and existing records.
  3. If Vercel is the active DNS host, connect the Vercel account that controls that exact domain. The integration asks for Domains: Read access.
  4. The portal reads the exact Vercel DNS zone and shows its records beside the public DNS results.

The trial does not add, change, or delete DNS records. It does not test whether email can be sent or received. Finding a DNS host does not prove that the connected Vercel account controls the domain; the account-zone read is the separate check.

Try it locally

From the repository root, run pnpm install, pnpm build, and pnpm demo:start; then open http://127.0.0.1:3100. The Vercel button appears only after the local server is configured with this integration's slug, client ID, and client secret. Keep the secret on your own machine; do not put it in the browser or repository.

If you no longer want the connection, remove the integration from your Vercel account. The local review can be cleared with Start again or by stopping the local server.
